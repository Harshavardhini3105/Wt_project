
# StudyPlanner 📚

StudyPlanner is a web-based study planning application designed to help
students organize their subjects, tasks, schedules, and study progress
in one place.

## 🚀 Features

- User registration and login
- Personalized onboarding
- Subject management
- Study task management
- Schedule generation
- Task completion tracking
- Study analytics
- User settings
- Dashboard for managing study activities

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 📂 Project Structure

| File | Description |
|------|-------------|
| `index.php` | Main entry page |
| `login.php` | User login |
| `signup.php` | User registration |
| `dashboard.php` | Main user dashboard |
| `subjects.php` | Subject management |
| `schedule.php` | Study schedule |
| `generate_schedule.php` | Schedule generation |
| `add_task.php` | Add study tasks |
| `complete_task.php` | Mark tasks as completed |
| `analytics.php` | Study analytics |
| `settings.php` | User settings |
| `schema.sql` | Database structure |

## ⚙️ Installation

1. Clone this repository.
2. Set up a PHP development environment such as XAMPP.
3. Create a MySQL database.
4. Import `schema.sql` into the database.
5. Configure the database connection in `db.php`.
6. Start the Apache and MySQL servers.
7. Open the project in your browser.

## 🎯 Purpose

The purpose of StudyPlanner is to provide students with a simple
platform for organizing their study activities and monitoring their
progress.
